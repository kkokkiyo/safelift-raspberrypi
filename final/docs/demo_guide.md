# Demo Guide

1. Stand 2 to 3 meters from the webcam.
2. Run `python main.py --camera auto --use_mock_sensors --no_gemini` for a no-key template report demo, or omit `--no_gemini` after setting `GEMINI_API_KEY`.
3. Confirm that skeleton overlay and phase text are visible.
4. Perform one slow squat.
5. Watch short rule-based feedback during motion.
6. Press Space or Enter when the repetition is done.
7. Check `outputs/reports/rep1_report.txt` and the dashboard report panel.
